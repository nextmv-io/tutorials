# Orchestrate multiple models

Code for the orchestrate multiple models tutorial, using Nextpipe. Based on the
following example:

* [Avocado price optimization example authored by Gurobi][gurobi-example].

For the example, you will find two directories:

* `original`: the original example without any modifications.
* `nextmv-ified`: the example converted into multiple Nextmv applications.

Go into each directory for instructions about running the decision workflow.

[gurobi-example]: https://www.gurobi.com/jupyter_models/avocado-price-optimization/
